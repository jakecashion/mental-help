# Rule-based decision tree for care level recommendations — no AI in the clinical path

Care level recommendations are generated by a rule-based decision tree, not an LLM or any probabilistic model. In a healthcare context, a hallucinated or confidently wrong recommendation is not a minor inconvenience — it is a danger. A 99.99% accurate LLM is not acceptable when the 0.01% failure mode is directing a family in crisis to the wrong level of care. Rule-based logic means outputs are deterministic, auditable, and reviewable by a clinician before they ever reach a real user.

This decision is open to revisitation if LLM reliability guarantees improve substantially, but the bar is very high.

## Considered Options

- LLM-generated recommendations — rejected due to hallucination risk in a safety-critical context
- Hybrid (rules for safety escalation, LLM for care level) — rejected for the same reason; the boundary between safety and care level is too blurry to split cleanly
